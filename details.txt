Functional Requirements

The system should:

Upload answer sheet images.
Extract handwritten text using OCR.
Clean and preprocess extracted text.
Extract keywords from the answer key.
Compare student answers with answer keys.
Calculate semantic similarity scores.
Generate marks automatically.
Display evaluation results to the user.
Non-Functional Requirements

Fast evaluation process.
Accurate text extraction.
Secure file handling.

Limitations of Handwritten Text Extraction
1. Handwriting Quality Dependency

The OCR system performs best with neat handwriting. Poor, cursive, or highly stylized handwriting may reduce accuracy.

2. Image Quality Issues

Blurred images, shadows, low lighting, or skewed scans can affect text extraction.

3. Mixed Language Problems

The system may struggle when multiple languages are written in the same answer sheet.

4. Special Symbols and Diagrams

OCR cannot accurately understand:

Mathematical equations
Flowcharts
Diagrams
Complex symbols

without additional specialized models.

5. Strike-Through Text

Crossed-out words may sometimes be detected as valid text despite preprocessing.

6. Spelling Errors

Excessive spelling mistakes can reduce semantic similarity scores even when the answer meaning is correct.

7. Layout Variations

Unusual answer sheet formats, overlapping text, or irregular spacing may impact extraction accuracy.

8. Context Understanding Limitation

The system measures semantic similarity but does not fully understand deep context like a human evaluator.
